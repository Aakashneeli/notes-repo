# Mission: Professional Python ownership

## Why
Build toward independently creating and explaining Python-first AI backends. This week,
turn text-processing rules into a maintainable package whose validation, configuration,
logs and dependencies you can reason about without a generated main implementation.

## Success looks like
- Implement, test and debug split/normalize/metadata behavior from explicit contracts.
- Explain type hints, validation, settings, imports, logs, pure functions and effects.
- Read a real small repository and defend your own module diagram and design choices.
- Reproduce the package locally and make a changed requirement after a delay.

## Constraints
- Python exposure and basic Git are disclosed; independent fluency is not established.
- Flexible pace, progressive hints, runnable local feedback and evidence-based assessment.
- Preserve previous weeks and all learner work; work only inside the notes repository.
- No paid services, credentials, publishing or deployment. Main implementation is learner-owned.

## Out of scope
- DSA, NeetCode, interview algorithms, complexity drills and their records.
- Detailed FastAPI, database, AI framework or cloud lessons; full earlier-week recreation.
