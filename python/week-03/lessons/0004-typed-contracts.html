Describe values precisely

Use annotations to clarify allowed values without mistaking them for runtime validation.

Read a signature as a promise

def label(value: str | None) -> str accepts a string or None and promises a string result. list[str] means a list containing strings; dict[str, int] maps string keys to integer values. str | int is a union. str | None is also called optional, but it does not make an argument omittable: a default such as = None does that.

Annotations communicate with readers, editors and optional static checkers. Plain Python does not reject a wrong argument merely because a hint exists. If a function calls .strip on an integer, the failure happens at that operation. Runtime validation is a separate boundary in lesson 5.

Hint 1

Check identity with None before calling string methods.

Hint 2 and explained answer
if value is None:
    return "(untitled)"
return value.strip()

The first branch returns early. Below it, value is the string case. Using if not value would incorrectly collapse empty strings into the missing case.

Expected: one pass. Variation: explain what changes if the signature is value: str | None = None. Answer: callers may now omit the argument; permitted value types did not change.
