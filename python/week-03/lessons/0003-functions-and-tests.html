Bridge only the function, exception and pytest skills needed for the text lab.

A tiny trace

A pure function computes from its arguments without changing outside state. def width(s): return len(s.strip()) takes " hi ", creates "hi", measures 2, then returns 2 to its caller. Printing inside width would send text to a stream; it would not supply a usable return value unless you also returned one. If execution reaches the end without return, Python returns None.

For the exercise, a comprehension [len(line) for line in lines] evaluates one length for each input string in order. For ["hi", "", "猫"] the results are 2, 0, 1. This ordinary collection task supports text metadata; no interview exercises are involved.

Expect one pass after implementation; initially NotImplementedError is deliberate. -k lengths selects the matching test; -q reduces output. An assertion compares actual and expected behavior. A traceback's last line identifies the exception; move upward to your first relevant frame to locate the call and value. An import error during collection is infrastructure, not the expected starter failure.

Apply the feedback loop to text

Read the normalize/split/summarize contracts in src/text_workbench/core.py. Leave these assessed implementations to your own attempt. Read tests/test_core.py: parametrization runs the same assertions over independent data rows. This week's chosen rules collapse whitespace, lowercase, preserve punctuation, and count normalized characters and whitespace tokens. A token is not necessarily a linguistic word.

Trace " Hello WORLD hello " by hand: normalized "hello world hello", tokens ["hello", "world", "hello"], metadata {"characters":17,"words":3}. Character count includes normalized spaces. "" gives zero characters and zero tokens. Unicode length is Python code points, not bytes or necessarily visible glyphs.

Run uv run pytest tests/test_core.py -q after your implementation. Debug a whitespace-only failure by printing repr(input), repr(normalized) and actual tokens temporarily. A common bug is splitting on a literal space too early, leaving empty tokens. Another is counting raw characters instead of normalized ones.
