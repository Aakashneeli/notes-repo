# AI as tutor

1. State your prediction and attempt before requesting help.
2. Ask for one hint, a failing test explanation, or critique of your design.
3. Record assistance in weekly-logs/week-03.md. Rebuild the small idea with help closed.
4. Explain every changed line and demonstrate a changed input after a delay.

Completed practice examples are labelled. Main project functions and design decisions
remain yours. Do not count copied implementations, supplied tests or author verification
as learned. No external messages, account changes or publishing are part of this workspace.
