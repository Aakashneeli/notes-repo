Week 3 glossary

module
A Python file with definitions and possibly top-level statements. Imports may execute top-level code.
package
An importable grouping of modules; this project uses an __init__.py marker.
distribution
The installable project described by metadata; its name need not equal its import name.
public contract
Behavior callers can rely on: inputs, outputs, errors and permitted side effects.
internal helper
Implementation detail; a leading underscore signals intent, not access enforcement.
pure function
A calculation based on its inputs without externally observable side effects.
side effect
An observable interaction beyond returning a value: file access, logs, environment reads or mutation of outside state.
union
A type permitting alternatives, such as str | int.
optional value
A value allowed to be None, such as str | None; a default separately permits omission.
validation
Checking/parsing a boundary value into a model with specified types and constraints.
serialization
Converting a record into a transport/storage representation such as JSON text.
dataclass
A standard-library class helper that generates methods from fields; ordinary type hints do not validate runtime values.
settings
Validated application configuration loaded at an explicit entry boundary.
logger / handler / formatter
Event recipient / destination adapter / representation builder.
structured event
An event with machine-readable named fields, here a JSON object.
dependency injection
Supplying a collaborator, such as a reader function, rather than constructing or locating it secretly.
LLD
Low-level design: responsibilities, interfaces and relationships between program units.
coroutine
An async function execution that can suspend and resume under scheduling.
event loop
The scheduler running ready asynchronous tasks and handling waits.
blocking
Occupying a thread so its event loop cannot run other tasks during that operation.
fixture
Reusable test setup, such as a temporary directory or log capture.
regression test
A check that exposes a previously observed bug if it returns.
character / token
Here: Python code point / whitespace-separated normalized text unit. Neither promises human linguistic segmentation.

Use these meanings in your README and diagram. Return to the relevant lesson for a worked example.
