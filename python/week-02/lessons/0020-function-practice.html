can_process(name, enabled)

Return True only when enabled is a boolean True and name ends with .txt. Inputs are a string and a bool; suffix matching is case-sensitive.

can_process("notes.txt", True) → True
Hint 1

Write the two required conditions separately before combining them.

Hint 2

Both must be true, so combine enabled with the suffix check using and.

Worked answer · after your attempt
def can_process(name, enabled):
    return enabled and name.endswith(".txt")

For the declared bool input this produces a bool. With enabled False the suffix check is unnecessary. A .TXT name does not match this contract.

describe_count(count)

For a nonnegative integer, return empty for 0, one file for 1, and many files for larger values.

describe_count(1) → "one file"
Hint 1

Write three cases in words before writing if/elif/else.

Hint 2

Return from each selected branch; do not print. Use == for comparisons.

Worked answer · after your attempt
def describe_count(count):
    if count == 0:
        return "empty"
    if count == 1:
        return "one file"
    return "many files"

The first return ends the call for zero. The second ends it for one. Only larger allowed inputs reach the final return. Negative input is outside this drill contract.

total_bytes(sizes)

Return the sum of a list of nonnegative integer byte sizes. An empty list gives zero. Use an explicit loop for this drill so you can trace the running value.

total_bytes([12, 8, 5]) → 25
Hint 1

Where should you initialize the running total so it is not reset each iteration?

Hint 2

Initialize once before the loop; return only after the loop finishes.

Worked answer · after your attempt
def total_bytes(sizes):
    total = 0
    for size in sizes:
        total = total + size
    return total

The trace is 0 → 12 → 20 → 25. With an empty list the body never runs and total remains 0. This is preparation for accumulating a direct file count.

keep_nonblank(lines)

Return original nonblank lines in order. A line is blank if strip() produces an empty string. Do not remove spacing from retained lines or mutate the input.

keep_nonblank([" ", "  note\n"]) → ["  note\n"]
Hint 1

Use a cleaned version to decide; keep the original version in the output.

Hint 2

Append line, not line.strip(), once your condition accepts it.

Worked answer · after your attempt
def keep_nonblank(lines):
    result = []
    for line in lines:
        if line.strip():
            result.append(line)
    return result

The condition inspects a temporary stripped string. The output preserves the original value. This separates selection from formatting and avoids silently changing user data.
