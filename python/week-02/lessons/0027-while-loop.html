Week 02 / Foundation

Make a loop stop for a reason

Read one step, try it, then pause. These are completed teaching examples; proposed repairs and variations are learner exercises.

Use for when visiting a known collection. Use while when repetition depends on a condition that can change. In a terminal tool, a forgotten update can keep a program running forever; a trace helps you see why it will stop.

Completed bounded example

From the course root, save this as practice/while-demo.py and run python practice/while-demo.py.

attempt = 1
while attempt <= 3:
    print(f"attempt {attempt}")
    attempt += 1
print("finished")

“finished” prints once after the loop. The condition is checked before each iteration, including the first. += 1 calculates the old value plus one and rebinds attempt. The value 4 causes the next condition to fail; there is no fourth body execution.

Your variation

Write a countdown from 3 to 1, then print “ready”. Predict all output first. Do not test an unbounded loop deliberately; if your program unexpectedly keeps running, Ctrl+C interrupts it and Python may show KeyboardInterrupt.

Hint 1

Start at 3 and choose a condition that is false at zero.

Hint 2

Subtract one inside the body after printing.

Explained answer · after your attempt
remaining = 3
while remaining > 0:
    print(remaining)
    remaining -= 1
print("ready")
assert remaining == 0

Output is 3, 2, 1, ready, each on its own line. The assertion passes without output. Starting at 0 skips the body and prints ready immediately.

Common mistakes

Putting the update outside the loop means the condition sees the same value forever. Putting continue before the update skips it and can cause the same problem. Replacing > with >= includes zero and prints one extra number. Trace the final successful condition and the first unsuccessful one.

Recall and explain-back

Why is a for loop natural for the file counter's directory entries? You already have entries to visit. A while loop adds state you would have to maintain. Rebuild the countdown tomorrow from only the output contract; then vary its initial value to 1 and 0.
