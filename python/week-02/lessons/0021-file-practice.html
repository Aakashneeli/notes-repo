first_token(line)

Return the first whitespace-delimited token. Return an empty string for an empty/whitespace-only line. Preserve token case.

first_token("  ERROR disk full\n") → "ERROR"
Hint 1

Split with no explicit separator so whitespace runs are handled for you.

Hint 2

Check whether any tokens exist before indexing element zero.

Worked answer · after your attempt
def first_token(line):
    parts = line.split(maxsplit=1)
    if not parts:
        return ""
    return parts[0]

A blank line becomes an empty list. Its index zero does not exist. The explicit guard makes the empty-input behavior clear before extracting a token.

read_utf8(path)

Accept a pathlib.Path. Return the file text decoded as UTF-8, with newlines retained as read_text returns them. Let missing-file errors propagate.

read_utf8(Path("message.txt")) → the file’s text
Hint 1

The Path object has a method for reading text.

Hint 2

Specify encoding="utf-8" rather than relying on a machine default.

Worked answer · after your attempt
def read_utf8(path):
    return path.read_text(encoding="utf-8")

Constructing a Path does not open a file. This method performs the I/O and may raise. The caller can decide how to present the error.

parse_json(text)

Return the Python value parsed from JSON text. Support any valid JSON value. Let JSONDecodeError propagate for invalid text.

parse_json("[true, null, 2]") → [True, None, 2]
Hint 1

You receive text, not a filename. Choose the JSON operation that consumes text.

Hint 2

json is imported for you in exercises.py. Do not use eval or string replacements.

Worked answer · after your attempt
def parse_json(text):
    return json.loads(text)

loads handles JSON syntax and returns the represented value. It need not be a dict. Invalid syntax should not be hidden behind an empty default value.
