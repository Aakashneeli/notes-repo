Week 02 / Foundation

Try terminal and Git tasks without a recipe

Read one step, try it, then pause. These are completed teaching examples; proposed repairs and variations are learner exercises.

Use these small challenges after lessons 02–07. Each has hints and an explained answer. Starting directory for terminal and setup tasks:

cd /home/an10/code/notes-repo/python/week-02

1. Find the last actual error

Print only the last ERROR-level line from the sample log, without editing it. The word ERROR inside an INFO message must not match.

Hint 1

Search contents with rg, then pass the matching text to tail.

Hint 2

Anchor ERROR at the start and include the separator after it.

Explained answer · after your attempt
rg '^ERROR ' projects/week-02-toolbox/data/app.log | tail -n 1

Expected: ERROR storage unavailable. The anchored expression matches the sample format’s level; the pipe sends matching lines to tail, which retains the last. This shell expression is narrower than the Python project contract, which also accepts leading whitespace and tabs.

2. Read a file from another location

Change to projects/week-02-toolbox/data, then read the course README using a relative path. Explain each upward step.

Hint 1

The course root is above data, the toolbox, and projects.

Hint 2

Use one .. per parent, then README.md.

Explained answer · after your attempt
cd projects/week-02-toolbox/data
cat ../../../README.md
cd ../../..

You move up from data to toolbox, from toolbox to projects, then to the course root. The final cd returns your shell there. cat itself does not change directory.

3. Undo staging without losing an edit

First complete the staging lab. Start inside practice/staging-lab with the committed text “two” and working text “three”. Stage notes.txt, then remove it from the proposed next commit while keeping the working text.

Hint 1

You want to change the index, not overwrite the working file.

Hint 2

Use restore with its --staged option; then inspect both diffs.

Explained answer · after your attempt
git add notes.txt
git restore --staged notes.txt
cat notes.txt
git diff --cached
git diff

cat prints three. The staged diff is empty. The ordinary diff shows two becoming three. git restore without --staged would target the working file, which is not the requested operation.

4. Identify the interpreter

Return to the course root, then enter projects/week-02-toolbox. With uv sync completed, display the Python executable used by the project and explain why it differs from command -v python in an unactivated shell.

Hint 1

Ask Python about itself while running it through uv.

Hint 2

sys.executable gives the running interpreter’s path.

Explained answer · after your attempt
uv run python -c "import sys; print(sys.executable)"

The path ends in the toolbox .venv/bin/python (or its interpreter launcher). uv runs in the project environment; command -v in your outer shell follows that shell’s PATH. Installing a project package affects import availability, not where a relative data path starts.
