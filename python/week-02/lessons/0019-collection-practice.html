add_filename(files, name)

Return a new list with name appended. Leave the input list unchanged.

add_filename(["a.txt"], "b.txt") → ["a.txt", "b.txt"]
Hint 1

If result = files, do you have a new list?

Hint 2

Make a shallow copy, append to the copy, then return that copy.

Worked answer · after your attempt
def add_filename(files, name):
    result = files.copy()
    result.append(name)
    return result

A direct assignment would alias the original. The elements here are strings, so copying the outer list satisfies this contract. append itself returns None.

read_level(record)

Return the value under the level key; if the key is absent, return INFO. An explicitly present empty value remains empty.

read_level({"message": "ready"}) → "INFO"
Hint 1

Compare indexing with dict.get. Which offers a missing-key fallback?

Hint 2

Do not use value or "INFO" here: that would also replace an explicitly empty string.

Worked answer · after your attempt
def read_level(record):
    return record.get("level", "INFO")

Missing and empty are distinct cases. get uses its default only when the key is absent. This resembles reading optional configuration.

known_levels(levels)

Return a set of distinct level strings. Preserve spelling and case; no normalization is requested.

known_levels(["INFO", "ERROR", "INFO"]) → {"INFO", "ERROR"}
Hint 1

A set stores unique values. You can construct it from the input list.

Hint 2

Set display order is not part of the answer. Compare sets as values.

Worked answer · after your attempt
def known_levels(levels):
    return set(levels)

There is no interview algorithm here: you are choosing the built-in representation for distinct values. INFO and info remain distinct.
