tidy_name(raw)

Remove surrounding whitespace and lowercase a filename. Return the new string; do not print.

tidy_name("  REPORT.TXT  ") → "report.txt"
Hint 1

Start with raw.strip(). What does that return?

Hint 2

String methods can be chained because strip returns a string.

Worked answer · after your attempt
def tidy_name(raw):
    return raw.strip().lower()

Neither method changes raw. Calling strip before lower makes the two intentions visible. The empty string remains empty.

make_label(name, count)

Return the exact text name: count files. count is an integer; no singular/plural special case is required.

make_label("uploads", 3) → "uploads: 3 files"
Hint 1

Use an f-string to place both argument values in the output.

Hint 2

Check spacing and punctuation against the example before changing logic.

Worked answer · after your attempt
def make_label(name, count):
    return f"{name}: {count} files"

The count is formatted as text for display. We are not doing arithmetic or parsing input. Returning lets the caller decide whether to print.
