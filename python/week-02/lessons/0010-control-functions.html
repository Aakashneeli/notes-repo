The idea

A conditional chooses a block; indentation defines that block. A for loop visits items; continue skips to the next iteration and break exits the loop. A while loop repeats while its condition is true, so ensure something changes that condition. A function receives arguments through parameters and gives a caller a result with return. Printing displays a value but does not return that value.

Read the primary source: Python: control flow and functions

Build the mental model

Walk through a function call

def greeting(name):
    message = f"Hello, {name}"
    return message

result = greeting("Asha")
print(result)
StepWhat runsState / consequence
1def greeting(name): ...Define the function; do not run its body yet
2greeting("Asha")Bind local parameter name to "Asha"
3message = ...Create local message "Hello, Asha"
4return messageEnd this call and give that string to the caller
5result = ...; print(result)Store returned string, then display it

name and message are local to that call. Reading message outside the function normally gives NameError. Different calls can use different arguments without overwriting a caller’s unrelated names. A function with no executed return returns None. Code after an unconditional return in the same path will not execute.

Trace a loop on paper

for name in ["a.txt", "b.log", "c.txt"]:
    if name.endswith(".txt"):
        print(name)
print("done")

The indentation places the conditional inside the loop and its print inside the conditional. The final print is outside both. A return inside a loop exits the entire function on that iteration; it does not just advance the loop. A continue advances the loop; a break exits the loop but execution can continue after it.

    return name.endswith(".txt")

files = ["notes.txt", "app.log", "draft.txt"]
for name in files:
    if is_text_file(name):
        print(name)
