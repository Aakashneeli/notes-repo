# Template: learning record

Use only after the learner demonstrates understanding, discloses prior knowledge, corrects a misconception or confirms a changed mission. Do not turn lesson coverage into a learning record.

Create `learning-records/0001-descriptive-name.md` for the first actual record; increment later records.

```markdown
# Short title of what was learned or established

One to three sentences explaining the demonstrated insight and how it changes the next teaching step.

## Evidence
The concrete user attempt or explanation that supports the claim.
```
