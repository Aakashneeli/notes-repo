Week 02 / Foundation

A shared vocabulary.

Use these meanings consistently in lessons, code reviews, and explain-backs.

Terminal
The interface where you interact with a shell and see program output.
Shell
The command interpreter that parses commands and starts programs.
Operating system
The system that manages processes, files, memory and access to devices.
Learning OS
This course’s repeatable study routine, distinct from the computer operating system.
Process
A running instance of a program, with its own environment and state.
Working directory
The directory used as the starting point for relative paths.
Absolute path
A path starting at filesystem root, such as /tmp/note.txt.
Relative path
A path interpreted from the current working directory, such as data/app.log.
Environment variable
A named string passed in a process environment to configure behavior.
PATH
The environment variable listing directories used to find executable commands.
Permission
An access rule such as read, write, or execute for owner, group, and others.
Standard output / stdout
The normal result channel; shell > can redirect it to a file.
Standard error / stderr
The diagnostic channel, separate from normal output.
Exit status
The number returned to the shell; zero conventionally means success.
Repository
A project’s tracked history and associated Git data.
Working tree
The checked-out files you can edit.
Staging area / index
The selected file content that will enter the next commit.
Commit
A recorded snapshot with metadata and parent history.
Branch
A movable name identifying a line of commits.
Remote
A named location for another Git repository.
Pull request / PR
A proposal to review and merge a branch on a hosting service.
Interpreter
The program that executes Python code.
Virtual environment
An isolated Python environment for a project’s installed packages.
Dependency
Code or tooling a project needs; runtime and development requirements serve different purposes.
Lockfile
A tool-managed record of resolved dependencies, committed for repeatable setup.
Module
An importable unit of Python code, commonly a .py file.
Package
A group of modules; this course uses a regular package directory with __init__.py.
Function
A named callable that receives inputs and may return a result.
Parameter / argument
A parameter names a function input; an argument is supplied at a call.
Mutation
Changing an existing object rather than creating a replacement object.
Exception
A runtime signal that normal execution cannot continue at that point.
Traceback
The chain of execution locations leading to an exception.
JSON
A text format for structured values; parsing converts it into Python objects.
Contract
The specified inputs, outputs, side effects, and failure behavior of a function.
Fixture
Reusable test setup/data; pytest’s tmp_path supplies an isolated temporary directory.
REPL
An interactive read–evaluate–print loop; Python shows >>> when ready for a statement.
Argument
A value supplied to a command or function call; command-line arguments begin as strings.
Method
A callable accessed through an object, such as name.strip().
Truthiness
How a value is interpreted in a condition; empty built-in collections and zero are false.
Short-circuit evaluation
Skipping the right operand of and/or when the left operand already determines the choice.
Aliasing
Two names referring to the same object; mutation through one name can be visible through the other.
Regression test
A check added for a discovered bug so a later change is less likely to reintroduce it.
CLI
Command-line interface: arguments, useful output, diagnostics and an exit status.
Standard library
Modules supplied with Python, including json, pathlib and argparse.
Type hint
An annotation describing expected types; ordinary Python execution does not automatically enforce it.
