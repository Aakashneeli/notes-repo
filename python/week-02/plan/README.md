# Week 2 study sequence

This is the named Foundation syllabus, at your pace. Each numbered lesson is a short reading plus a separate attempt. Stop after one tangible win; a project can take several sessions. No daily hour target is required.

| Block | Read and practice | Ready to proceed when |
|---|---|---|
| A: learning and terminal | 01–03; make a tiny script, navigate, quote paths, search logs | You predict where a relative path points and explain each command's output |
| B: surroundings and Git | 04–06; environment demo, staging, conflict and remote labs | You can show committed/staged/working versions and explain a local push/pull |
| C: Python setup and values | 07, 28, 08; sync toolbox; lesson 18 string exercises | You identify the interpreter and return an exact text result |
| D: collections | 09 and 19 exercises | You preserve an input list, read optional dict fields, and use a set |
| E: decisions and functions | 10, 27, then 20 exercises one at a time | You trace all iterations, return values, and an empty input |
| F: file boundaries | 11 and 21 exercises | You distinguish paths, text, parsed values and input errors |
| G: debug and read scaffolding | 22–25, then 17 | You locate a failure and explain the supplied wrapper/checker/test |
| H: projects | 12 counter, 13 JSON, 14 filter; use contracts and focused tests | Each tool works, has a meaningful commit and an explanation |
| I: ownership | 15, assessment; 26 docs-reading exercise | Fresh-clone run, new test, real mistake note, own-word reference and explain-back |

[Lesson 16](../lessons/0016-foundation-workshop.html) is a practice navigation hub, not an extra large assignment. The desk links all these lessons in study order; filename numbers reflect their creation order.

## A session that fits your energy

For a short session: recall one previous idea (3 minutes), read one explanation (10 minutes), try one exercise (10–15 minutes), and record what surprised you (2 minutes). Longer sessions can contain two such rounds with a break. If an exercise takes longer, resume it next time.

Try before hints. Open hint 1, retry; then hint 2 if necessary. Beginner answers are explained for self-study. Close any answer you read and recreate it with another input later. The three project implementations remain yours to write.

## Review that tests memory

Next day: close the lesson and redo its recall prompt. Three days later: mix an older path or Git task with a new Python function. One week after completion: rebuild one tool function from the contract in a fresh attempt file. Put actual dates and outcomes in the [session log](../weekly-logs/week-02.md).

Use [progress](progress.md) to record attempts and [assessment](assessment.md) for ability evidence. Nothing starts marked learned.
