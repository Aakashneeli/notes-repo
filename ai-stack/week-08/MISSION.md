# Mission: Own a manual retrieval backend
## Why
Build toward independently designing, debugging and explaining Python-first AI backend software.
Make answers traceable to stored source text and diagnose whether retrieval or generation failed.
## Success looks like
- Implement and test ingestion, search and cited answers without an orchestration framework.
- Explain every stored field and context-selection decision.
- Evaluate 15–25 questions and repair one observed failure with a regression check.
## Constraints
- Python/Git exposure without demonstrated independent fluency; flexible pace and progressive hints.
- Local practice first; learner owns assessed code and design decisions.
- No paid provisioning, publishing, account changes or external messages.
## Out of scope
- DSA, NeetCode, algorithm interviews and complexity drills.
- Detailed agent frameworks, model serving or cloud deployment lessons.
