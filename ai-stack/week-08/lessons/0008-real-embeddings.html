Week 08 / Lesson 08

Replace known vectors with text embeddings

Run or explicitly defer a real encoder and describe what its result proves.

Known vectors isolate mechanics. To test semantic retrieval, encode both documents and queries using the same real model. This step adds a model download and CPU inference, so keep its evidence separate from the no-download checks.

Read the supplied probe

The official FastEmbed guide documents the encoder generator and first-use download behavior used here.

practice/semantic_probe.py uses FastEmbed to load the named MiniLM encoder, embeds two tiny sentences, derives the dimension from the returned query, writes to an in-memory Qdrant collection, and prints both ranked hits. Leave the probe unchanged for its first run. embed yields arrays; tolist() converts each into the ordinary float list the store expects. No hosted generation occurs.

Prerequisites: internet access for the first weight download, enough local disk/RAM for the package and model, and a compatible CPU/runtime. Review the model license/card first. A GPU is not required for this small probe; latency depends on hardware. The optional package is separate from the core lock so offline practice does not silently download a model.

Understand the adapter seam

The project accepts embed(text), a callable returning a vector. A callable is simply something you can call with parentheses, such as a function or object with a call method. Load a real model once, then wrap it with a function that embeds one string. Recreating the encoder per request wastes startup work. Set Store's dimension from the encoder output and ensure query/document settings match.

# Shape sketch for learner integration, not a completed service
encoder = TextEmbedding(model_name="sentence-transformers/all-MiniLM-L6-v2")
def embed_one(text):
    return next(encoder.embed([text])).tolist()

next takes the first yielded item; a one-element input list yields one vector. For batches, preserve input order so each vector stays attached to its own chunk. This sketch still needs your lifecycle, version configuration and failure handling.

A guided failure

The old collection contains 3-dimensional synthetic vectors. Can you point the 384-dimensional encoder at it?

Hint

Check the collection's invariant before the first write.

Explained answer

No. Create a separately named/path-isolated collection for the real model, re-embed all intended source text, and use that model for queries. Do not delete the earlier database to make this experiment work, and do not mix old and new scores in one evaluation report.

Independent variation: change the query to “Can I send my purchase back?” and compare semantic ranking with the simple keyword fixture. Write one reason it may still miss. A successful two-sentence probe proves that an encoder and local store can exchange vectors; it does not prove quality on the 20-question corpus. If download or hardware blocks this step, retain the exact error and mark real-semantic evidence pending; continue the deterministic project work.
