Week 08 / Lesson 03

Understand one raw model request

Trace messages, response envelopes and streamed fragments.

A model API is an HTTP boundary: your application sends a model choice and messages; it receives generated content or a transport/provider error. The system role expresses application instructions, the user role carries the question, and assistant messages represent previous replies. Roles organize input; they are not an authorization system.

Read the envelope

Run the completed message example from the weekly root:

.venv/bin/python -m practice.examples messages
.venv/bin/python -m practice.provider_probe

Read practice/provider_probe.py. By default it prints a request and sends nothing. request_body builds a dictionary; HTTPX's json= serializes it. A non-streaming chat response wraps generated text under choices[0].message.content. The project adapter must return that content string, not the entire envelope.

{"choices":[{"message":{"role":"assistant","content":"Hello."}}]}

Trace: select key choices → first list item at index 0 → its message dictionary → content string. An empty choices list would fail at index 0; a refusal or missing content requires deliberate handling rather than pretending it is a normal answer.

Provider compatibility has limits

Groq's compatibility documentation supplies its base URL; OpenRouter's API overview describes another compatible boundary. Matching request shapes does not mean all models support the same structured-output or streaming features. Choose a current model from the provider's official model list and check its feature support.

A live probe is a learner action: it needs an account, a key, network access and a pricing/budget check. It can incur cost. Send only the supplied harmless greeting. From the weekly root, after choosing an available model:

export LLM_PROVIDER=groq
export LLM_MODEL='replace-with-current-provider-model-id'
read -rsp 'Provider key: ' LLM_API_KEY
export LLM_API_KEY
.venv/bin/python -m practice.provider_probe --live
unset LLM_API_KEY

The placeholder must be replaced. Do not paste a secret directly into shell history or commit it. The probe has a 20-second timeout and suppresses raw error bodies. A 401 calls for checking credentials, a 400 for checking model/request compatibility, a 429 for respecting limits. Blindly retrying everything can multiply charges. Record provider, model, status and latency in the weekly log, without the key. No live call was needed to prepare this workspace.

Streaming awareness, one small drill

Streaming delivers fragments over time; the first event may carry a role and no text. Server-sent events also have framing that must be decoded before you have dictionaries. The streaming reference supports that distinction. We practise only assembling already-decoded content; this is not a network-stream parser.

Edit practice/exercises.py, function text_from_deltas. Read test_exercises.py, leave its checks unchanged, then run:

.venv/bin/python -m pytest practice/test_exercises.py -k deltas -q

Expected after implementation: one pass. Before implementation: one NotImplementedError. “Thirty ” and “days.” must become “Thirty days.” without a missing space.

Hint

Collect content only when choices is nonempty and content is not null. Join exactly, without inserting spaces.

Explained beginner answer
parts = []
for event in events:
    choices = event.get("choices", [])
    if choices:
        text = choices[0].get("delta", {}).get("content")
        if text is not None:
            parts.append(text)
return "".join(parts)

get supplies a default for absent keys; it does not magically validate arbitrary input. The drill's contract assumes decoded provider-shaped events.

Independent variation: add an empty-string fragment and two sentences split mid-word. Predict the exact result. Streaming a prefix of JSON does not produce a valid final object; validation belongs after complete assembly.
