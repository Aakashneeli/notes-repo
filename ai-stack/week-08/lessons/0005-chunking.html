Week 08 / Lesson 05

Choose boundaries you can explain

Trace overlapping chunks and implement deterministic chunk records.

Chunking divides a source into pieces that can be retrieved independently. A whole long document may contain many unrelated topics; a tiny excerpt may omit the condition that makes a statement true. A chunk is useful only if it retains enough context to answer a question.

Watch the indices

Our teaching fixture uses words, not model tokens. split() normalizes whitespace into a list of words; words[start:end] includes start but excludes end. With size 4 and overlap 1, inspect the completed window function:

# Start: ai-stack/week-08
.venv/bin/python -m practice.examples chunking

Input words are one, two, three, four, five, six, seven. Window [0:4] yields “one two three four”. The next start is 4−1=3; window [3:7] yields “four five six seven”. Stop at the end. Do not emit an extra “seven” tail. The overlap repeats “four” so a fact crossing that boundary can remain nearby.

Overlap must be smaller than size: overlap 4 with size 4 makes no forward progress. Zero overlap is valid. Before writing chunks, implement safe_overlap in exercises.py, then run:

.venv/bin/python -m pytest practice/test_exercises.py -k overlap -q
Hint

Check types before comparisons. In Python, bool is an integer subclass, so use an exact type check for this contract.

Explained beginner answer
return (type(size) is int and type(overlap) is int
        and size > 0 and 0 <= overlap < size)

The short-circuit “and” chain avoids invalid comparisons after a bad type. Requiring an integer keeps slicing valid.

Fixed windows versus semantic-ish boundaries

Suppose a document says “Returns: Keep your receipt. Shipping: Express takes two days.” A fixed character cut can split “receipt”; a word window may combine unrelated headings. A semantic-ish splitter can separate paragraphs/headings, gather complete sentences until a target size, then split oversized paragraphs with a fallback. This is a heuristic, not proof of semantic completeness. Abbreviations, tables and very long sentences break naive punctuation splitting.
