Baseline probes

Fill weekly-logs/week-08.md: What is the difference between a JSON string and a dictionary? What does return give a caller? Why can a valid HTTP response still contain a wrong answer? State uncertainty explicitly.

Hint

Separate wire text, an in-memory value, function control flow and factual correctness.

Explained answer

'{"x":1}' is text; {"x":1} is a dictionary accessed by key. JSON parsing converts between them. A return hands a value back, unlike printing to the terminal. HTTP 200 says a request was handled, not that its content is supported by evidence.

If these block you, read only the functions/tests bridge, validation lesson or HTTP message lesson needed, then retry. Independent variation: explain why printing an answer inside a function may leave its caller with None.
