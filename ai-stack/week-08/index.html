AI stack / Week 08

Answers need evidence.

Build and explain a manual retrieval backend, one inspectable boundary at a time.

Source week 8: Raw LLM APIs, Embeddings, Vector DBs, Manual RAG, and Retrieval Evaluation. Work here: ai-stack/week-08/. Deliver a manual ingest/search/ask API, comparison, diagram, 15–25-question evaluation and tests.

Start with Lesson 1 — Find your starting point. Project code is deliberately unfinished. Prepared material is not learner mastery.
  • 01Find your starting pointChoose a prerequisite bridge using evidence, then run one known-good example.
  • 02Follow one document into the systemIdentify the extraction-to-chunking seam without replacing unfinished earlier work.
  • 03Understand one raw model requestTrace messages, response envelopes and streamed fragments.
  • 04Validate an answer, then decide whether to retrySeparate JSON syntax, schema validity and evidence support.
  • 05Choose boundaries you can explainTrace overlapping chunks and implement deterministic chunk records.
  • 06Read a vector as a representationPredict simple similarity scores and reject incompatible embeddings.
  • 07Persist and filter a local vector storeVerify retrieval scope and persistence using known vectors.
  • 08Replace known vectors with text embeddingsRun or explicitly defer a real encoder and describe what its result proves.
  • 09Build context that supports a cited answerChoose evidence, separate it from instructions, and validate citation identity.
  • 10Expose ingest, search and askConnect the pieces through a testable HTTP boundary.
  • 11Locate the first failed stageBuild a golden set and distinguish retrieval, context and generation failures.
  • 12Choose a store with a reasonCompare setup, filters, persistence and deployment fit without extra provisioning.
  • 13Explain the pipeline without copyingCollect independent evidence, review code boundaries and schedule retrieval.
