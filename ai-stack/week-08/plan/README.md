# Flexible sequence
Start from the weekly root for every command unless explicitly directed elsewhere.
1. Lessons 1–2: baseline, install, choose bridge; stop when one document trace makes sense.
2. Lessons 3–4: raw messages, streaming awareness, schema and bounded repair.
3. Lessons 5–7: chunks, vectors and real local persistence/filtering. Implement these project pieces.
4. Lesson 8: real embedding probe; label a blocked download honestly, then continue local work.
5. Lessons 9–10: context/citations, answer boundary, API, local smoke; wire semantic/live adapters when ready.
6. Lessons 11–12: 15–25 assessed questions, controlled diagnosis, conceptual store comparison.
7. Lesson 13: source reading, diagram, explain-backs, Git review and independent assessment.
Return after roughly 2 days and 1 week for closed-notes retrieval. Repeat a small prerequisite only
when a failed attempt demonstrates a gap. Sessions can stop at any lesson section.
