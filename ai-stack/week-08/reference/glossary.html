Reference / Week 08

Words with precise jobs

Document
A whole source with identity, ownership, version and extracted text.
Chunk
An excerpt with enough provenance to locate it in a source.
Embedding
A numerical representation produced by a particular model/configuration.
Dimension
Number of coordinates in a vector. Equal dimension alone does not imply compatible models.
Cosine similarity
Alignment of two nonzero vectors; larger is closer for this lab's metric, not a probability.
Payload / metadata
Stored fields beside the vector, including tenant, source identity, version and text.
Tenant
An ownership boundary supplied by trusted application identity, not guessed from text.
Upsert
Insert a new identity or update the record with that same identity.
Idempotent ingestion
Repeating the same ingestion produces the same intended stored state.
Top-k
At most k ranked candidates, after required access filters.
Context
The actual selected evidence sent to the generator, potentially a subset of retrieved candidates.
Reranking
Reordering retrieved candidates using a further relevance judgement.
Citation
An identifier the application resolves to supplied source evidence. Identity validity is not factual support.
Schema
Rules for the structure and types of a value.
Abstention
An explicit insufficient-evidence response instead of an unsupported answer.
Golden question
A question with independently checked source/answer criteria for evaluation.
Hit@k
Here: fraction of answerable questions with any expected document among top-k. Not all-source recall.
Hallucination note
A recorded unsupported claim with the relevant missing or contradictory evidence.
Mock / fixture
A controlled replacement or known input used to isolate behavior; not evidence of a live integration.
