Find the first broken boundary

  1. Input: trusted tenant, valid document/question, correct version?
  2. Chunk: complete needed sentence, stable IDs and correct offsets?
  3. Embedding: same model/configuration and dimension, finite nonzero values?
  4. Store: completed write, reopened correct path, no old-version ambiguity?
  5. Retrieval: expected source present after required filter and top-k?
  6. Context: useful retrieved source actually selected within budget?
  7. Generation: oracle-context answer supported, schema valid, repair bounded?
  8. Output: cited IDs belong to selected context, claims supported, errors sanitized?

Record question ID, safe metadata, selected IDs, error class and timings. Do not log keys or private text. Keep synthetic, real-encoder and live-provider evidence separate.
