# Assistance without giving away ownership

Before asking for help, write a prediction, actual output and smallest failing case in weekly-logs/week-09.md. Ask for one hint, a state trace or review of your attempt. Record any borrowed code and explain each line. Do not ask for a finished workflow.py. The supplied bridge, tests and ticket examples are tutor code; the graph, API integration, threshold decision and analysis are yours.

Use progressive answers only after an attempt. For delayed recall, close solutions and references. Passing after copying is practice evidence, not independent completion.
