Week 9 glossary

Read a term at first use; return here for recall. Definitions describe this course’s usage.

State
The values carried between workflow steps; a snapshot, not automatically durable storage.
Patch
A node’s returned changes to selected state keys.
Node
Named operation that reads state and returns updates.
Edge
Fixed or conditional transition to another operation.
Compilation
Converting a graph builder into an executable graph; this does not run a query.
Workflow / agent
A workflow has predefined control paths. A model-directed agent can choose actions dynamically. A graph can support either.
Tool
An application capability exposed through a controlled callable interface.
Validation / authorization
Validation checks input shape and values; authorization checks whether the caller may perform the requested access.
Tenant
An isolation boundary for data ownership; derive it from trusted server identity, not a prompt.
Fallback
A deliberate terminal response when the workflow cannot safely answer.
Checkpoint / thread
A saved workflow snapshot and the history identifier grouping such snapshots. A thread ID is not an authentication token.
Run / trace / span
An observed operation; its related operation tree; a timed segment in that tree. LangSmith represents operations as runs.
Latency / throughput
Time for one request versus amount of work completed per unit time.
Model card
Repository documentation covering model identity, use, limitations and licensing evidence.
Tokenizer / chat template
Text-to-token-ID mapping and the model-specific formatting of role messages.
Parameter / inference
A learned numeric model value; executing existing weights to obtain outputs.
Pipeline
Transformers helper coordinating preprocessing, model inference and postprocessing.
Quantization / GGUF
Reduced numeric precision; a file format containing tensors and metadata. Neither guarantees quality or runtime fit.
KV cache
Attention keys/values retained to avoid repeating work during generation; consumes memory with context and concurrency.
Continuous batching
Scheduling new inference requests into work as capacity becomes available rather than waiting for a fixed batch to finish.
OpenAI-compatible API
A familiar HTTP contract shape; it does not promise feature or model-behavior parity.
Fixture
Controlled substitute used to test behavior. Our fixture performs no semantic retrieval or model generation.
