Start at ai-stack/week-09. Preserve your smallest failing input and actual output before changing code.

ObservationInspect next
ModuleNotFoundErrorWhich Python ran? Use .venv/bin/python and the pinned installation, then rerun author checks.
NotImplementedErrorLearner stubs are intentionally unfinished. Identify the corresponding lesson before implementing.
KeyError in a nodeFind the first reader and expected writer of that state key; trace the route.
Unexpected node or repeated loopCheck branch labels and unconditional edges; use updates stream and the step limit.
False success on weak retrievalInspect retained hits and whether generation was called; do not fix it with a nicer fallback string.
Unauthorized lookupTrace trusted tenant origin and filtering inside the access boundary.
No live tracesVerify live flag, project/region/workspace config and upload errors; never print keys.
Slow requestInspect root wall time and relevant child spans; don't double-count parents.
Local inference OOM or swapCheck weights plus runtime/context memory. Stop the process; reduce workload or use a smaller model.
Fluent but wrong answerCompare retrieved text, template, generation and validation separately. Citation IDs alone are not support.
