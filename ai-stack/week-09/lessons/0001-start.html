Three probes before installation

  1. For s={'question':'refund','hits':[]}, what remains after s.update({'hits':['c1']})?
  2. Explain: stored text → query embedding → filtered search → context → generated answer → citation validation. Which steps could run without a model?
  3. If a request supplies tenant='blue', should the server trust it as proof of identity?
Hint — open after trying

The question remains; hits becomes ['c1']. Retrieval needs an encoder in real semantic RAG; formatting context, filtering and checking IDs can be ordinary code. A caller-supplied tenant is not authenticated identity.

Make a reproducible environment

Read requirements.in for direct dependencies and requirements.lock for exact resolved versions; leave the lock unchanged during the lessons. Python 3.12 is used to avoid unrelated compatibility work. uv venv creates an isolated interpreter directory. If Python 3.12 is absent, uv may download it. Installation needs network access but no paid account.

uv venv .venv --python 3.12
uv pip sync requirements.lock --python .venv/bin/python
export LANGSMITH_TRACING=false
.venv/bin/python -m practice.examples
.venv/bin/python -m pytest maintenance/test_examples.py maintenance/test_infrastructure.py -q

If .venv already works, skip its creation and synchronize packages. Expected example output: a dictionary with text “Database outage”, urgent True, queue “on-call”; then {'status': 'open'}. Author checks should pass. Missing imports indicate environment trouble, not your learning gap. practice/examples.py is a completed support-ticket example; run/read it, leave it intact. practice/__init__.py makes that folder importable. Tests under maintenance/ check tutor examples/fixtures; do not implement project code to make these pass.

The dependencies have distinct jobs: LangGraph executes nodes; its installed langchain-core dependency provides shared runnable/tracing interfaces; LangSmith instruments runs; Pydantic validates data; FastAPI exposes HTTP; HTTPX powers test requests; pytest runs checks; Uvicorn serves HTTP. You do not need the full LangChain package or a hosted model to branch on a string.

.gitignore excludes environments, runtime/ outputs, secrets and caches. Do not inspect installed dependency files one by one. .venv/ is installed infrastructure, __pycache__/ and pytest caches are generated, and runtime/ is created when you save experiments. Shared assets/course.css imports the existing local course style; leave it unchanged while studying.
