# Mission: Own a bounded AI workflow

## Why
Become able to build, debug and explain a Python AI backend independently. Extend understood retrieval and answer functions into a stateful, inspectable workflow, and choose model execution tools based on evidence.

## Success looks like
- Implement a graph-backed RAG endpoint, bounded lookup tool and meaningful failure tests.
- Trace state and trust boundaries through successful and unsuccessful requests.
- Inspect at least ten LangSmith runs and measure a small real local model.
- Explain a hosted/local/vLLM choice using hardware, quality, privacy and load constraints.

## Constraints
- Python/Git exposure without demonstrated independent fluency; flexible pacing and fading hints.
- No usable GPU is assumed. No publishing, provisioning, external messages or account changes by the tutor.
- Main implementation and assessed decisions remain learner work.

## Out of scope
- DSA, interview exercises and complexity drills.
- Full model training, GPU deployment, cloud provisioning and detailed future-week design.
