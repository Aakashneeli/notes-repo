Working vocabulary

LLD / HLD
Code-level responsibility design / running-system design.
Interface / protocol
The operations a caller needs; Python Protocol expresses a structural type contract without runtime input validation.
Dependency injection
Passing a dependency into a function/object so a caller chooses the implementation.
Service / repository
Workflow policy / storage-facing operations. Boundaries hide different reasons for change.
Container (C4)
A deployable application or data store; not necessarily a Docker container.
Trust boundary
A change in authority or trust when data/actions cross components or parties.
Timeout / deadline
A wait limit for an operation / the total time budget remaining for a request.
Retry / backoff / jitter
A new attempt / increasing delay / randomized delay to spread attempts.
Idempotency
Repeating an operation has the same intended effect; it does not mean executing exactly once.
Circuit breaker
A failure-sensitive gate with closed, open and limited-probe recovery states.
Dead job
Work held for investigation after permanent failure or exhausted retries.
Log / metric / trace
An event record / an aggregate over observations / linked steps of one operation.
Request ID
A correlation identifier, never proof of identity or permission.
Latency / throughput
Elapsed time per request / completed requests per unit time.
p95
A sample's 95th percentile under a stated convention; not a worst-case guarantee.
Cache-aside / TTL
Read cache, then source on miss / expiration duration; neither grants authorization.
Rate limit
A policy bounding how much work an actor can request in a time window.
Atomic operation
A change that cannot be observed partially within its stated system boundary.
Index / cursor
A database access structure / a continuation position for a stable paginated ordering.
Batching / async I/O
Grouping work to amortize overhead / yielding while I/O waits so other tasks can progress.
Prompt injection / retrieval poisoning
Untrusted instructions steering a model / malicious or unreliable source content corrupting retrieval-based answers.
Token / cost estimate
A model-specific text unit / usage times explicitly identified rates; unknown usage is not zero.
ADR / runbook
A consequential choice with reasons and tradeoffs / a symptom-driven operational procedure.
Fixture / mock / live evidence
Supplied controlled prerequisite data/behavior / substituted dependency / an observation against the actual integration.
