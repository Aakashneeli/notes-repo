# Flexible sequence
Start with Lesson 1 and record actual prerequisite evidence. Split or repeat any stage; do not force this into seven sittings.

1. Lessons 1–2: predict a request, choose a tiny bridge if needed, implement one injected boundary.
2. Lessons 3–4: inspect the existing backend and make all five diagram views, distinguishing actual/proposed.
3. Lessons 5–6: reason through bounded failures, duplicates and dead-job recovery.
4. Lessons 7–8: interpret signals, implement safe events and wrapper, reproduce a failing test.
5. Lessons 9–10: document cache/rate-limit behavior; measure three latency configurations, then vary concurrency.
6. Lessons 11–12: security cases, four ADRs, runbook rehearsal, PR-style explanation.
7. Lesson 13: independent variation, explain-backs, exact-file local Git checkpoint.
8. Next session / 2–3 days / about a week: recall before reading, one new failure, defend a changed constraint.

[Coverage](coverage.md) describes syllabus; [assessment](assessment.md) describes independent ability; [progress](progress.md) stores learner evidence; [file map](file-map.md) introduces each supplied item.
