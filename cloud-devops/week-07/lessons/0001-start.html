Hint · open after trying

Separate a Python name, an HTTP message, a process, and a network location.

Explained answer · compare your reasoning

app:create_app means the create_app callable in app.py; --factory asks Uvicorn to call it. A 503 is an HTTP response; an uncaught exception needs server handling. Enqueued work may still be pending. localhost refers to the caller’s own network namespace, not every machine or container.
