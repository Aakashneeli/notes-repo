# Mission: Own a reproducible local backend

## Why
Build toward independently designing, debugging and explaining Python-first AI backends. Make the ingestion backend start predictably on another checkout and expose enough evidence to diagnose failures before adding AI dependencies.

## Success looks like
- Independently write and explain an API image and five-service Compose topology.
- Prove readiness, safe request correlation, persistence and actual worker completion.
- Write a working lint/test CI draft, an honest runbook and a failure/repair note.
- Explain and vary the system from memory with delayed retrieval.

## Constraints
- Python and basic Git exposure; earlier backend mastery is not established.
- Local preparation only, learner-owned assessed implementations, flexible pace.
- Preserve earlier projects and all progress; use a clearly labelled prerequisite fixture.
- No GPU, paid provisioning, publishing, account changes or messages.

## Out of scope
- Interview algorithm exercises and their associated logs.
- Detailed RAG, model providers, production deployment and future-week lessons.
