DeskUse in retrieval

Names you can point to.

Image
Packaged filesystem layers and runtime defaults; not a running process.
Container
An isolated running or stopped instance created from an image, with runtime configuration.
Build context
Host files made available to a build; COPY paths are relative to it.
Layer
A filesystem change contributing to an image; reusable during builds.
Tag / digest
A movable human name / a content identifier for an image.
Service
A Compose definition of a process, its image and runtime settings.
Published port
A host address/port forwarded to a container port.
Service DNS
Name resolution for services sharing a Compose network.
Named volume
Docker-managed data storage with a lifetime separate from a container.
Bind mount
A specific host path made visible inside a container.
Environment
Name/value settings read by a process at runtime; .env interpolation alone is not injection.
Health / readiness
Here: API responsiveness / success of required current dependency probes.
Middleware
A request/response wrapper that can act before and after downstream handling.
Request ID / job ID
A request-correlation label / the identity of durable queued work.
Structured event
A log record with predictable fields and types, serialized here as one JSON line.
Handler / formatter
Logging destination / conversion from a log record to emitted text.
CI runner
A machine executing the workflow job; assume no personal environment exists.
Fixture
Supplied bounded prerequisite behavior used to make the current lesson possible.
