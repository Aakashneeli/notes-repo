Probe before changing.

Python commands start at Week 7 root. Compose commands below start in projects/local-stack; always preserve the project name if using a fresh trial.

docker compose --env-file .env.example config --quiet
docker compose --env-file .env.example ps -a
docker compose --env-file .env.example logs --tail=50 api worker
docker compose --env-file .env.example exec api sh
docker compose --env-file .env.example down
Import failed
Check build context, COPY destination, WORKDIR and module:function target.
Name resolves, connection refused
Check target process and container port, then dependency readiness.
Host port busy
Inspect ss -ltn; choose a free host port without changing the internal port.
Healthy but jobs pending
Check worker status, queue name and importability. Connectivity is not consumption.
Password changed but login fails
Existing Postgres volume keeps its database role credentials; initialization variables do not rotate them.
JSON logs duplicated
Check repeated handler attachment and propagation; do not disable tests to hide it.

down preserves named volumes unless you explicitly request their deletion. No deletion or broad prune is part of this course. Log only allowlisted fields; don't save full resolved config containing real secrets.
