13 focused lessons. Local practice, a labelled prerequisite fixture, and learner-owned operational code. Progress is unassessed.

  1. 01Find your starting pointChoose the smallest prerequisite bridge that lets you explain a reproducible service.
  2. 02Run the prerequisite fixture checksTrace the supplied ingestion bridge without treating it as your completed earlier project.
  3. 03Build once, run twicePredict which values belong to an image and which belong to one running container.
  4. 04Package the ingestion applicationWrite the build recipe and explain every path from host context to runtime import.
  5. 05Let services find each otherChoose an address from the caller’s location and wire the five service boundaries.
  6. 06Keep data through container replacementSeparate service startup, dependency readiness and persistent state.
  7. 07Make health claims preciseImplement two endpoints whose status codes match the claims they make.
  8. 08Write logs a tool can readCreate a safe JSON event and explain how it travels to a log reader.
  9. 09Follow one request through middlewareCorrelate successful and failed HTTP responses without leaking request content.
  10. 10Diagnose the running stackFind the failing layer with a probe, then prove the repair with a real job.
  11. 11Make checks repeat on a clean runnerWrite a push/PR workflow and explain each process and working directory.
  12. 12Make the start path reproducibleProve a documented start command without relying on hidden local files.
  13. 13Prove ownership and retain itExplain, debug and vary the stack independently, then schedule delayed retrieval.
