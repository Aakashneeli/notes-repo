Roadmap 11 / Cloud

One backend.
A release you can explain.

AWS Deployment, CI/CD, Secrets, Cloud Logs, Runbooks, and Cost Control

Local teaching workspace. No AWS resources provisioned, endpoint deployed or learner mastery claimed. Work toward the $20/month constraint with a measured plan.

Source mapping and starting state · Mission · Flexible sequence

  1. 01Start with an honest deployment baselineChoose a backend and distinguish a rehearsal from a deployed endpoint.
  2. 02Price a bounded experimentCalculate an all-in estimate and explain why an alert cannot cap spending.
  3. 03Separate identity from network accessExplain one allowed action and one denied connection using distinct boundaries.
  4. 04Build an identifiable containerBuild the learner Dockerfile and distinguish container binding from host publishing.
  5. 05Draw the private traffic pathLocate a failed request at the network, host or application boundary.
  6. 06Inject configuration without baking secretsTrace a secret from its source to the process and rehearse a safe configuration failure.
  7. 07Choose storage and a runtime deliberatelyExplain S3, RDS, EC2, ECR/ECS and Lambda by the responsibility each owns.
  8. 08Make CI earn the right to releaseWrite a test/build workflow and explain the separate deployment identity boundary.
  9. 09Rehearse the EC2 releaseFollow a concrete host deployment procedure and record a real private endpoint only when observed.
  10. 10Follow an incident through logs and healthUse a request ID and release to investigate a 500 without leaking secrets.
  11. 11Promote only a verified releaseImplement a release gate and recover from a failed candidate without confusing code and data rollback.
  12. 12Close the experiment and prove ownershipCreate a resource-specific shutdown record and complete delayed retrieval without inventing mastery.
