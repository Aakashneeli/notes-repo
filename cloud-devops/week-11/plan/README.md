# Flexible Week 11 sequence

One outcome per lesson; pause whenever prediction and observation disagree.
No fixed daily schedule and no mastery assumed from earlier weeks.

1. [Start](../lessons/0001-start.html): baseline, fixture, environment, evidence.
2. [Cost](../lessons/0002-cost.html): budget before infrastructure.
3. [Identity](../lessons/0003-identity.html): IAM and packet access.
4. [Image](../lessons/0004-image.html): learner packaging and local smoke checks.
5. [Traffic](../lessons/0005-traffic.html): diagram and boundary diagnosis.
6. [Secrets](../lessons/0006-secrets.html): runtime config and rotation.
7. [Storage](../lessons/0007-storage.html): conditional S3, DB and runtime choices.
8. [CI](../lessons/0008-ci.html): write draft; release checks remain pending until lesson 11.
9. [Deploy](../lessons/0009-deploy.html): local rehearsal then learner live host if ready.
10. [Logs](../lessons/0010-logs.html): local incident analysis then separate cloud evidence.
11. [Rollback](../lessons/0011-rollback.html): implement gate, inject failure, return to CI.
12. [Shutdown](../lessons/0012-shutdown.html): cost closure, explain-back and delayed recall.

For safety of understanding, you may complete the *local portions* of lessons 10–11 before
the live portion of lesson 9. Budget/IAM/image prerequisites must precede live work.
If cloud is unavailable, complete local lessons and mark live evidence pending, not passed.
After about 2 days and 1 week, retrieve without notes; repeat weak mechanisms with variations.
