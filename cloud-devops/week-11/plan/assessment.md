# Completion evidence

Reading, time spent, author tests and copied commands do not establish completion.
For each result link an attempt, prediction, observation, explanation and new variation.

1. Independently package selected FastAPI app. Explain context/COPY/CMD/user/binding.
2. Run normal, missing-key, wrong-key and dependency-failure cases; interpret the statuses.
3. Price region/type/hours/storage/IP/logs/transfer without assuming credits; defend headroom.
4. Draw internet → SSH → host → container → handler; separate IAM from SG access.
5. Rotate a dummy secret and explain live source/delivery/readers/revocation.
6. Defend S3 applicability and database/runtime choice; if applicable test real app storage.
7. Implement workflow that runs lint/tests/build and cannot deploy an unchecked candidate.
   Describe exact artifact identity and trusted deployment credentials. Record hosted CI separately.
8. Deploy to learner-owned AWS and document real endpoint access, release and route results.
   If blocked, mark live work incomplete while preserving local evidence.
9. Find a deployed request's CloudWatch event and diagnose a 500 or missing logs.
10. Implement/test promotion gate; reject wrong release/unready status; rehearse rollback.
    Explain data migration limitations and downtime.
11. Inspect exact cloud inventory and shutdown residual costs; schedule delayed billing review.
12. Answer all four source explain-backs without the lessons, then vary a failure scenario.
    Repeat after spacing.

A useful tutor review asks you to predict a changed output, diagnose a new symptom and
defend one decision. It does not simply count checked boxes.
