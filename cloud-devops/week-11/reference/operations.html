Before promotion

Correct artifact + health 200 + readiness true + expected release + authorized/unauthorized behavior + recovery path. Before shutdown: exact IDs + retention decision + remaining-cost review.

Cost = planned usage × applicable rates + retained storage + transfer/logs + tax/reserve. Budget alerts are not a hard cap. Public IPv4 and disks can matter even in small labs.
