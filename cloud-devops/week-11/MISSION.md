# Mission: Operate one affordable backend

## Why
Independently deploy, debug and explain a Python AI backend, including its access paths,
configuration, release process and ongoing cost. Make the Week 11 cloud step deliberate
enough to support later integration.

## Success looks like
- Build and verify a Dockerized FastAPI release and a documented private AWS endpoint.
- Explain traffic, IAM and secrets; trace a production failure using logs and health.
- Write CI and rehearse rollback; account for ongoing costs within the $20/month constraint.

## Constraints
- Python/basic Git exposure; earlier projects unassessed and unfinished.
- Flexible short lessons with traces, feedback and reduced hints.
- Tutor creates local materials only; learner owns paid provisioning and external changes.

## Out of scope
- DSA, NeetCode, algorithm interviews, complexity drills and related logs.
- Full ECS/Lambda platforms, multi-region production and detailed capstone lessons.
