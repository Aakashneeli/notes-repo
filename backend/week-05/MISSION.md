# Mission: Own durable backend state

## Why
Build toward independently designing, debugging and explaining Python-first AI backends.
This week, make the Task API retain correct data across requests and restarts, including
failed and concurrent writes, so future document and job storage has a trustworthy base.

## Success looks like
- Write and explain 20 SQL queries without copying.
- Implement PostgreSQL models, repository access, migrations and atomic task/event writes.
- Test constraints, failures and persistence against PostgreSQL, then vary a requirement.
- Explain table relationships, query plans and each endpoint's database work.

## Constraints
- Python/basic Git exposure without demonstrated independent mastery; flexible pace.
- Preserve earlier work, use short worked traces and gradually reduced hints.
- Local practice only; no publishing, paid provisioning or external account changes.
- Learner completes the main implementation and evidence.

## Out of scope
- Interview algorithm practice, associated logs, unrelated earlier/future curricula.
- Redis, vector stores, RAG, cloud and deployment implementation.
