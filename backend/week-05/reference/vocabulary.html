Working vocabulary

Read at first unfamiliar term, then return to its lesson. This is a supplied vocabulary reference; it is not a mastered-knowledge GLOSSARY.md. The tutor may record demonstrated knowledge later.

Row / column
One stored record / one named typed field of each record.
Schema
A database namespace containing tables; also used informally for the structure of those tables. Lessons state which meaning is intended.
Primary key
Unique, non-NULL row identity.
Foreign key
A stored reference constrained to match a key in another (or the same) table; a nullable reference can be absent.
Constraint
A database-enforced validity rule, such as required values or uniqueness.
NULL
An absent/unknown value. Use IS NULL to test absence; it is not false or zero.
Join / cardinality
A query operation combining matching rows / the number of possible related rows.
Transaction
A database unit whose writes commit or roll back together.
Isolation
Rules governing what concurrent transactions can observe and how conflicting work is handled.
Engine / connection
SQLAlchemy's configuration and connection-pool entry point / a channel to the database.
Session
A SQLAlchemy unit coordinating mapped objects and transaction work; scope it to one concurrent operation.
Flush / commit / rollback
Send pending SQL / complete a transaction / undo uncommitted transaction work.
Repository
A chosen code boundary grouping database access. In this desk the caller owns commit.
Migration / revision
A schema transition program / its identifier in migration history.
Index / query plan
An additional lookup structure / the database's chosen operations for a query.
Fixture
Test setup and cleanup supplied around an exercise; it is not learner implementation.
Read for quick recall; definitions are supplied teaching aids, not evidence of learner mastery.
