# Flexible sequence
Status: unassessed. Split a lesson across sittings when prediction or debugging is hard.
1. Lesson 1: prerequisite probes; revisit only linked bridge material where needed.
2. Lessons 2–5: local DB, selects, writes, relationships; SQL Q01–Q20 in stages.
3. Lesson 6: transactions and a two-terminal concurrent-write observation.
4. Lessons 7–8: model syntax, session trace, repository seam.
5. Lesson 9: run unrelated migration demo, then create your project revisions.
6. Lessons 10–11: implement one vertical CRUD slice, then remaining operations and failure tests.
7. Lesson 12: measured index lab; add and explain a project index.
8. Lesson 13: diagram, migration notes and one code-reading trace.
9. Lesson 14: independent assessment and documentation/Git review.

Start each sitting with one prior output prediction before opening notes.
Return after roughly 1, 3 and 7 days (adjust to your schedule): recall then verify.
Advance on demonstrated small variations, not elapsed days. Return to the specific failed
mechanism when necessary. Learner fills progress.md, weekly log and evidence files;
tutor maintains coverage/file map/validation, not learner completion ticks.
