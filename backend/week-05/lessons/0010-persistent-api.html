Trace create before coding more operations

A POST body reaches TaskCreate. Annotated attaches string rules; StrictBool rejects strings/numbers used as booleans; extra="forbid" rejects unknown keys. The writer dependency accepts the local write key. repo opens a Session. transact begins the unit of work. Your repository inserts Task, flushes for ID, inserts TaskEvent and returns a dictionary. Transaction exit commits before create returns a 201 response. On a unique-title violation, rollback happens first, then the named expected constraint maps to 409.

Read schemas.py line by line. PATCH uses model_fields_set to distinguish omitted from explicitly supplied fields. model_dump(exclude_unset=True) passes only changes; a supplied false must survive. The validator rejects explicit None despite the optional internal defaults. Read app.py's create_app: an injected engine is owned by the caller (tests); an internally created engine is disposed at shutdown. Health reports that the HTTP process responds; it is not a database readiness proof.

Build a thin vertical slice

Start at the weekly root. Implement models.py/migrations and repository.create/get first. Run uv run alembic -c projects/task-api/alembic.ini upgrade head, then:

uv run uvicorn --app-dir projects/task-api app:create_app --factory --port 8055

--app-dir makes the flat project's modules importable, app:create_app names module:function, and --factory calls the function. Keep this terminal running. Open a second terminal and cd /home/an10/code/notes-repo/backend/week-05. Read supplied create.json (request sample; keep unchanged), then run:

curl -i -H 'X-API-Key: local-study-key' \
 -H 'Content-Type: application/json' \

In psql verify tasks and task_events contain the related rows. Record the returned ID; do not assume 1. Stop the API with Ctrl-C and restart the same command. GET the recorded ID: the same row must exist. If not, check DATABASE_URL, commits and accidental in-memory fallback.

Hint for a 500 during create

Look at the local traceback: NotImplementedError means an expected starter; undefined table means migrations/destination; an unexpected integrity error means inspect the exact violated rule. Do not turn every IntegrityError into “duplicate title.”

Explain the two-commit bug

If create commits Task before adding Event, the later exception cannot undo that earlier committed transaction. Use one outer commit for both writes and let a failure escape to rollback.
