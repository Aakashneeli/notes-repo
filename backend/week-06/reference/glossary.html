Week 6 glossary

Use after a first retrieval attempt. Return to the corresponding lesson for a worked trace.

Ingestion
Accepting, validating, storing and processing a document into usable text/metadata.
Router
HTTP adapter that declares endpoints and maps outcomes to responses.
Schema
Explicit data shape and validation rules; here Pydantic response models.
Service
Coordinator of the ingestion use case, independent of HTTP.
Repository
Interface for persisted metadata queries and updates.
Integration / adapter
Code that connects policy to storage or a queue.
Authentication / authorization
Verify a credential / decide which action on which resource is permitted.
Multipart / UploadFile
A body with named parts / FastAPI’s file-like representation of one uploaded part.
Bytes / text
Encoded octets counted for upload limits / decoded Unicode characters used for extraction.
CORS / origin
Browser cross-origin response policy / scheme, host and port tuple.
Storage key
Server-controlled internal identifier for bytes, distinct from original filename.
Transaction / compensation
Atomic database unit / separate cleanup action after a cross-system partial failure.
Parameter binding
Passing data separately from fixed SQL grammar.
Compare-and-set / claim
Update only if current state matches expected state / acquire permission to process a job.
Job / queue / worker
Tracked work / pending dispatch records / process executing work.
Pending / running
Accepted but unclaimed / claimed; running does not certify liveness.
Completed / failed / retrying
Usable result recorded / terminal unsuccessful attempt / classified for another attempt.
Idempotence
Repeating a job preserves the intended effect of one successful execution.
Retry / reconciliation
Another bounded attempt / comparing persistent facts and repairing inconsistent or stranded work.
Lease
Time-bounded claim with ownership/expiry rules, needed to recover abandoned work safely.
Ingress limit / rate limit
Bound an incoming request’s resource use / bound requests or work over a time window.
