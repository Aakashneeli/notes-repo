# Assistance without substituting for learning
Before asking, record your prediction and smallest failing example. Ask for a question or
one hint first, then an explanation. Keep real API keys and personal document contents out
of prompts and logs. Use only the harmless supplied samples for screenshots or shared traces.
Record help used in weekly-logs/week-06.md. Do not paste a complete generated main project;
write the assessed implementation and design decisions yourself. After any explanation,
close it and attempt a changed example. Tutor verification never marks progress learned.
