Treat an upload as untrusted bytes

Reject unsupported or oversized content before storing it.

Multipart is a request body format containing named parts. The field file carries a filename, a declared content type, and bytes. Those labels come from the client. UploadFile offers file-like access with spooling, but neither spooling nor a .txt suffix certifies safety. This lab accepts only nonempty UTF-8 plain text, with no NUL bytes, at most 1,024 bytes. PDF, archives, HTML and rich document parsing are deliberately unsupported.

Use a small limit so edge cases are easy to reproduce. Reject names containing slash, backslash or control characters, and empty names, with 400. Require a .txt suffix (case-insensitive) and a declared type of text/plain; otherwise 415. Decode strictly as UTF-8 and reject NUL with 415. Empty bytes receive 400; too many bytes receive 413. Text has no universal magic signature: a UTF-8 HTML fragment may still be text. Never render it as HTML or execute it, and do not claim this policy detects malware.

limit = 4
chunks = [b"ab", b"cde"]
# before first append: 0 + 2 <= 4, buffer becomes b"ab"
# before second append: 2 + 3 > 4, reject; never store b"abcde"

Read bounded() in the completed examples. In your async validator, await upload.read(n) returns up to n bytes; empty bytes mean end of file. await allows the surrounding coroutine to suspend while that operation completes. Track actual bytes, not only Content-Length. Use a bounded read loop and close the upload in finally, which executes on both success and error. The route/parser may already have received or spooled the request before this validator runs: this application check is not an ingress bandwidth or disk quota. Record the need for upstream body limits, timeouts and capacity controls.

First hint

Bytes decode into text; invalid UTF-8 raises UnicodeDecodeError, a ValueError subclass. Check empty input and NUL explicitly.

Explained beginner answer

For the beginner: reject not data or b"\x00" in data with ValueError, then return data.decode("utf-8"). For the project, translate decode failure into UploadProblem(415, "invalid_text"); keep size/type error codes distinct.
