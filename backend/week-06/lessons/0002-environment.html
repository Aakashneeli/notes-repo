Run one small mechanism

Prepare the environment and distinguish infrastructure success from learner completion.

pyproject.toml declares dependencies; uv.lock pins their resolved versions. Read both as supplied infrastructure, but do not edit the lock by hand. FastAPI handles HTTP, Uvicorn serves it, python-multipart parses file forms, HTTPX powers the test client, and pytest runs checks. The optional rq extra installs Redis/RQ clients; it starts no Redis server. SQLite is in Python's standard library.

uv sync --locked creates .venv/. This generated environment, Python bytecode, pytest caches and the uv cache are not lessons or evidence; do not inspect every installed file. .gitignore keeps those and runtime/ and .env out of ordinary Git adds. Read it once; do not force-add ignored credentials or runtime data.

Read practice/examples.py, the completed small mechanisms, and practice/test_examples.py, their checks. These are deliberately separate from the unfinished practice/exercises.py and practice/test_exercises.py. A test beginning test_ is discovered by pytest. assert a == b fails if the observed value differs from the expected one. A temporary-path fixture gives each test a new directory, so checks cannot overwrite your project data.

A traceback is a path to evidence

Read the final exception first, then find the nearest frame inside this workspace. ModuleNotFoundError often means the wrong interpreter or starting path; use uv run. Project imports work under pytest because pythonpath includes projects/ingestion. Uvicorn will receive --app-dir projects/ingestion explicitly. Do not fix imports by copying package files.

First hint

The rejection happens before extending the buffer with the offending chunk.

Explained beginner answer

It raises ValueError("too_large"). A limit of four permits exactly four bytes, so changing > to >= would incorrectly reject a valid boundary upload.
