Three probes, before setup

  1. Given def f(x): return len(x.split()), predict f("one two") and explain why two spaces do not create a word.
  2. Trace a request from route to service to repository and back. Which layer chooses an HTTP status?
  3. If a database write succeeds but the file write fails, what can the next request observe?
First hint

Trace the string, the list returned by split(), and then len(). A route speaks HTTP; a repository speaks persistence.

Explained beginner answer

The first result is 2. The route maps outcomes to HTTP; the service coordinates work. A successful metadata write with no file leaves a broken reference. File storage and database commits are separate operations, so their ordering and cleanup need explicit design.
