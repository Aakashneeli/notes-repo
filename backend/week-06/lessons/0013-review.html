Delayed retrieval

After roughly two days, draw the five-state graph and explain a crash without notes. After about a week, vary the size limit and add an edge test, then explain what would change if a worker used another machine. Use the blank review template to record predictions before reopening material. The schedule is flexible: delay enough to require recall, without imposing a fixed daily pace.

Independent variation

Choose a new transient storage failure, implement an isolated test double in test_learner.py, and prove it cannot turn an unsuccessful extraction into completed. For the base path, failed is sufficient; describe rather than pretend to implement automatic retries. Explain exactly which behavior your check cannot establish about a killed process.

Primary reading: starlette.dev — relevant official guide. See annotated sources for supporting API and security documentation.
