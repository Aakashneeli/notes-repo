Week 04 / FastAPI

HTTP and FastAPI glossary

Use when a term in a lesson blocks understanding; read, do not fill in. Return to the active lesson after lookup.

HTTP request / response
Client message and server reply: method/target versus status, each with headers and possibly a body.
Resource / representation
The named thing (/tasks/1) versus its transmitted description (JSON fields).
Route / router
A method/path handler mapping; a router groups mappings under a prefix.
Path / query / header / body
Resource identifier in the URL path; selection options after ?; message metadata; payload bytes.
Schema / validation / serialization
A data contract; checking/converting input against it; encoding values for transmission.
Dependency / injection
A callable that supplies a value or enforces a condition; the framework arranges the call and provides its result.
Authentication / authorization
Recognizing a credential/identity; deciding which actions that identity may perform.
In-memory / app factory / lifespan
State held only in this process; a function constructing a fresh app; setup and cleanup around its running lifetime.
ASGI / Uvicorn
The Python interface between asynchronous servers and apps; the server used here to serve that app over HTTP.
Offset / limit / total
Matching rows skipped; maximum returned; matching count before slicing.
Test fixture / regression
Controlled setup/cleanup reused by tests; a check preventing recurrence of a demonstrated bug.
OpenAPI / Swagger UI / Postman
Machine-readable API description; interactive browser documentation; client for saved manual requests/checks.
Omitted / null / false
No field supplied; an explicit empty JSON value; a concrete boolean value. Do not treat them as interchangeable.
