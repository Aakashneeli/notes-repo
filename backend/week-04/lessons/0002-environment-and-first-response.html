Week 04 / lesson 02

Run a real response

Install the declared environment and distinguish example, starter and generated files.

The server is a process that waits for requests. FastAPI describes what that process should do; Uvicorn connects the app to an HTTP listening socket. 127.0.0.1 means this computer and port 8004 identifies our practice listener. No cloud, GPU, paid service or external credentials are needed. Installing packages requires internet and disk space. Postman is a later learner action; all Python checks work without it.

Read projects/task-api/pyproject.toml: project metadata and Python range; FastAPI/Pydantic/Uvicorn runtime dependencies; pytest/HTTPX/Ruff development tools; setuptools build backend discovering src/task_api. HTTPX underlies TestClient. uv.lock records resolved versions; leave it unchanged unless deliberately updating dependencies. Editable installation makes the package importable while you edit its source. --project selects the environment but does not change your shell's current directory.

.venv/ is generated installed code, not learner evidence. Python bytecode, pytest/Ruff caches and package metadata are also generated; .gitignore keeps those and local secrets out of Git. Read it; do not inspect every dependency. The lessons share assets/course.css and print.js; these are tutor-maintained presentation infrastructure. The script opens hint disclosures for printing and restores them afterward. No browser click saves progress.

Verified environment notes

The locked stack was tested with Python 3.14.7. Current Starlette emits deprecation warnings for HTTPX-backed TestClient and an AnyIO alias; these checks still pass. Warnings are not failed assertions. Keep the lockfile for this course and treat a future client migration as a deliberate dependency update with retesting. In the author sandbox, TestClient stalled while entering its context; the same tests passed in a normal unrestricted local process. If your process hangs, interrupt it and inspect the environment before rewriting a correct route.

Debug the layer that failed

Connection refused means no listener, a wrong port or a stopped process, not a validation error. Address already in use means another process owns the port: choose another local port in both terminals rather than killing an unknown process. Module not found suggests the wrong starting directory or module path. Dependency download failure is setup infrastructure; NotImplementedError in your exercise is an intentional starter. Do not confuse either with a learned skill.
