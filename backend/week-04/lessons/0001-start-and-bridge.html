A tiny prerequisite, not an earlier course

A dictionary maps a key to a value. row["done"] reads a value; a function's return hands a result to its caller. Printing merely displays it. {**row, **changes} creates a new dictionary: unpack row, then overwrite matching keys with changes. With {"done": True, "title": "Tea"} and {"done": False}, predict a new row with False and the original title. The original row stays True. Testing if changes.get("done") would lose False because False fails the condition; presence and truth are different questions.

The type dict[str, object] documents string keys and arbitrary values. Hints do not automatically reject bad runtime data. Pydantic models supply the separate validation step. BaseModel is a class you inherit to declare fields; Label(text="tea") constructs an instance and model_dump() produces a dictionary. The completed practice/bridge.py shows this bridge. practice/exercises.py contains your unfinished drills; its tests are supplied checks to read and run, not weaken.
