Python in one small example

from pathlib import Path

def describe(path):
    info = {"name": path.name, "is_file": path.is_file()}
    return info

for entry in Path("data").iterdir():
    record = describe(entry)
    if record["is_file"]:
        print(f"file: {record['name']}")

List: ordered items. Dict: named fields. Set: unique membership. A function returns a value; print displays it. A relative filesystem path is not an import path.

The three environment artifacts

  • pyproject.toml: declared requirements and project metadata.
  • uv.lock: resolved versions; commit it.
  • .venv/: installed environment; ignore it.
