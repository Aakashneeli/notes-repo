Round 1 · Values into useful text

Suggested pace: one function per 5–15 minute attempt. Run python practice/foundation-drills/check.py strings from the course root. Earlier groups do not have to pass to run this group.

tidy_name(raw)

Remove surrounding whitespace and lowercase a filename. Return the new string; do not print.

tidy_name("  REPORT.TXT  ") → "report.txt"
Hint 1

Start with raw.strip(). What does that return?

Hint 2

String methods can be chained because strip returns a string.

Worked answer · after your attempt
def tidy_name(raw):
    return raw.strip().lower()

Neither method changes raw. Calling strip before lower makes the two intentions visible. The empty string remains empty.

make_label(name, count)

Return the exact text name: count files. count is an integer; no singular/plural special case is required.

make_label("uploads", 3) → "uploads: 3 files"
Hint 1

Use an f-string to place both argument values in the output.

Hint 2

Check spacing and punctuation against the example before changing logic.

Worked answer · after your attempt
def make_label(name, count):
    return f"{name}: {count} files"

The count is formatted as text for display. We are not doing arithmetic or parsing input. Returning lets the caller decide whether to print.

Round 2 · Choose and update a collection

Suggested pace: one function per 5–15 minute attempt. Run python practice/foundation-drills/check.py collections from the course root. Earlier groups do not have to pass to run this group.

add_filename(files, name)

Return a new list with name appended. Leave the input list unchanged.

add_filename(["a.txt"], "b.txt") → ["a.txt", "b.txt"]
Hint 1

If result = files, do you have a new list?

Hint 2

Make a shallow copy, append to the copy, then return that copy.

Worked answer · after your attempt
def add_filename(files, name):
    result = files.copy()
    result.append(name)
    return result

A direct assignment would alias the original. The elements here are strings, so copying the outer list satisfies this contract. append itself returns None.

read_level(record)

Return the value under the level key; if the key is absent, return INFO. An explicitly present empty value remains empty.

read_level({"message": "ready"}) → "INFO"
Hint 1

Compare indexing with dict.get. Which offers a missing-key fallback?

Hint 2

Do not use value or "INFO" here: that would also replace an explicitly empty string.

Worked answer · after your attempt
def read_level(record):
    return record.get("level", "INFO")

Missing and empty are distinct cases. get uses its default only when the key is absent. This resembles reading optional configuration.

known_levels(levels)

Return a set of distinct level strings. Preserve spelling and case; no normalization is requested.

known_levels(["INFO", "ERROR", "INFO"]) → {"INFO", "ERROR"}
Hint 1

A set stores unique values. You can construct it from the input list.

Hint 2

Set display order is not part of the answer. Compare sets as values.

Worked answer · after your attempt
def known_levels(levels):
    return set(levels)

There is no interview algorithm here: you are choosing the built-in representation for distinct values. INFO and info remain distinct.

Round 3 · Make a decision and return a result

Suggested pace: one function per 5–15 minute attempt. Run python practice/foundation-drills/check.py flow from the course root. Earlier groups do not have to pass to run this group.

can_process(name, enabled)

Return True only when enabled is a boolean True and name ends with .txt. Inputs are a string and a bool; suffix matching is case-sensitive.

can_process("notes.txt", True) → True
Hint 1

Write the two required conditions separately before combining them.

Hint 2

Both must be true, so combine enabled with the suffix check using and.

Worked answer · after your attempt
def can_process(name, enabled):
    return enabled and name.endswith(".txt")

For the declared bool input this produces a bool. With enabled False the suffix check is unnecessary. A .TXT name does not match this contract.

describe_count(count)

For a nonnegative integer, return empty for 0, one file for 1, and many files for larger values.

describe_count(1) → "one file"
Hint 1

Write three cases in words before writing if/elif/else.

Hint 2

Return from each selected branch; do not print. Use == for comparisons.

Worked answer · after your attempt
def describe_count(count):
    if count == 0:
        return "empty"
    if count == 1:
        return "one file"
    return "many files"

The first return ends the call for zero. The second ends it for one. Only larger allowed inputs reach the final return. Negative input is outside this drill contract.

Now close this answer, change one input, and explain the output before running. Return tomorrow and implement it again from the contract.

total_bytes(sizes)

Return the sum of a list of nonnegative integer byte sizes. An empty list gives zero. Use an explicit loop for this drill so you can trace the running value.

total_bytes([12, 8, 5]) → 25
Hint 1

Where should you initialize the running total so it is not reset each iteration?

Hint 2

Initialize once before the loop; return only after the loop finishes.

Worked answer · after your attempt
def total_bytes(sizes):
    total = 0
    for size in sizes:
        total = total + size
    return total

The trace is 0 → 12 → 20 → 25. With an empty list the body never runs and total remains 0. This is preparation for accumulating a direct file count.

Now close this answer, change one input, and explain the output before running. Return tomorrow and implement it again from the contract.

keep_nonblank(lines)

Return original nonblank lines in order. A line is blank if strip() produces an empty string. Do not remove spacing from retained lines or mutate the input.

keep_nonblank([" ", "  note\n"]) → ["  note\n"]
Hint 1

Use a cleaned version to decide; keep the original version in the output.

Hint 2

Append line, not line.strip(), once your condition accepts it.

Worked answer · after your attempt
def keep_nonblank(lines):
    result = []
    for line in lines:
        if line.strip():
            result.append(line)
    return result

The condition inspects a temporary stripped string. The output preserves the original value. This separates selection from formatting and avoids silently changing user data.

Round 4 · Cross the text/file boundary

Suggested pace: one function per 5–15 minute attempt. Run python practice/foundation-drills/check.py io from the course root. Earlier groups do not have to pass to run this group.

first_token(line)

Return the first whitespace-delimited token. Return an empty string for an empty/whitespace-only line. Preserve token case.

first_token("  ERROR disk full\n") → "ERROR"
Hint 1

Split with no explicit separator so whitespace runs are handled for you.

Hint 2

Check whether any tokens exist before indexing element zero.

Worked answer · after your attempt
def first_token(line):
    parts = line.split(maxsplit=1)
    if not parts:
        return ""
    return parts[0]

A blank line becomes an empty list. Its index zero does not exist. The explicit guard makes the empty-input behavior clear before extracting a token.

Now close this answer, change one input, and explain the output before running. Return tomorrow and implement it again from the contract.

read_utf8(path)

Accept a pathlib.Path. Return the file text decoded as UTF-8, with newlines retained as read_text returns them. Let missing-file errors propagate.

read_utf8(Path("message.txt")) → the file’s text
Hint 1

The Path object has a method for reading text.

Hint 2

Specify encoding="utf-8" rather than relying on a machine default.

Worked answer · after your attempt
def read_utf8(path):
    return path.read_text(encoding="utf-8")

Constructing a Path does not open a file. This method performs the I/O and may raise. The caller can decide how to present the error.

Now close this answer, change one input, and explain the output before running. Return tomorrow and implement it again from the contract.

parse_json(text)

Return the Python value parsed from JSON text. Support any valid JSON value. Let JSONDecodeError propagate for invalid text.

parse_json("[true, null, 2]") → [True, None, 2]
Hint 1

You receive text, not a filename. Choose the JSON operation that consumes text.

Hint 2

json is imported for you in exercises.py. Do not use eval or string replacements.

Worked answer · after your attempt
def parse_json(text):
    return json.loads(text)

loads handles JSON syntax and returns the represented value. It need not be a dict. Invalid syntax should not be hidden behind an empty default value.

Debug a small broken program

Predict the actual behavior of each snippet before running it in a disposable practice file. Repair it, then explain why the repair works.

The wrong type

retries = "2"
print(retries + 1)
Diagnosis and repair direction

TypeError: a string cannot be added to an integer. For arithmetic, convert retries with int(retries). For a display label, use formatting instead. The intended operation decides the conversion.

The lost list

names = ["one"]
names = names.append("two")
print(names)
Diagnosis and repair direction

It prints None. append mutates and returns None; call it without rebinding names.

The disappearing result

def title(name):
    print(name.upper())

result = title("notes")
print(result)
Diagnosis and repair direction

It prints NOTES and then None. Return the uppercase string from title, and leave display to the caller.

The early exit

def total(sizes):
    answer = 0
    for size in sizes:
        answer += size
        return answer

print(total([3, 4]))
Diagnosis and repair direction

It prints 3. Dedent return to after the loop so all entries contribute. The repaired version returns 7 and should also return 0 for an empty list.

The unsafe index

parts = "   ".split()
print(parts[0])
Diagnosis and repair direction

IndexError: splitting whitespace gives []. Check whether parts is nonempty before reading index zero.

The mistaken JSON source

import json
print(json.loads("data/example.json"))
Diagnosis and repair direction

JSONDecodeError: loads consumes JSON text, not a filename. Read the file to text before parsing, or practice with a JSON literal such as "42".
