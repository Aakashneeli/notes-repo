Explain the difference between a name, a value, and its type.

The idea

An assignment binds a name to an object. str is text, int is an integer, float is a floating-point number, and bool is true/false. Quotes make "3" text; int("3") converts it to an integer. None represents absence. Python infers types at runtime; names are not boxes permanently restricted to one type.

Strings have zero-based indexes. Slices exclude the end index. Strings are immutable: operations such as strip() return a new string. An f-string inserts expression values into text. Experiment in the interpreter before saving your own version in practice/values.py.

Expected output: 2 3. The equals sign is assignment, not a claim that both expressions are equal forever. == asks whether values compare equal; != asks whether they differ. Strings use + for concatenation, while numbers use it for addition. Choose the intended operation instead of converting types until an error disappears.

A method is a function accessed through an object, such as name.strip(). Parentheses call it. name.strip refers to the method without executing it. Empty parentheses mean no explicit arguments; they do not mean “this does nothing.”

Truth values are not the text “true” and “false”

Empty strings, empty collections, zero, False and None behave as false in a condition. Nonempty strings such as "false" and "0" behave as true. This matters when reading environment settings. bool("false") does not parse a textual boolean; you must define which strings your program accepts. Use is None for an absence check and == for value comparisons.

Mini-check

Predict bool(""), bool(" "), and "12" == 12. Answers: False, True, False. One space is still a character; the string and integer are distinct values.

Try it yourself

raw = "  report.txt  "
name = raw.strip()
count = "3"
print(type(count).__name__)
print(int(count) + 2)
print(name[0], name[-4:])
print(f"{name}: {count} files")
print(raw == name)

Write down all five outputs before execution. Then intentionally try count + 2. Read the exception’s last line and repair the operation. Next, make a separate string for the same filename in uppercase without changing name.

Expected result · open after your attempt

Outputs: str; 5; r .txt; report.txt: 3 files; False. Adding a string to an integer raises TypeError. Use conversion when doing arithmetic, or convert the number to text when joining text. name.upper() produces a new string; it does not mutate name.
