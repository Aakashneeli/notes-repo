The idea

You own count_files(folder) in src/week1_toolbox/file_counter.py. The supplied command wrapper parses one path and prints your result. It catches expected input failures and reports them to standard error. Read the wrapper line by line; if __name__ == "__main__" runs main when executed as a script.

Contract: count regular files immediately inside a directory, including hidden files; do not recurse into subdirectories; exclude symlinks even when they point to files. Missing directory → FileNotFoundError. A file where a directory is expected → NotADirectoryError. Return an integer. Empty directory → 0.

Read the primary source: Python: pathlib reference · Python: argparse tutorial and reference · pytest: first tests

Build the mental model

Break the task into observations you can already make

Before counting anything, use a Python prompt in the toolbox to bind folder = Path("data/count"). Evaluate folder.exists(), folder.is_dir(), and then iterate its children while printing each child’s name, is_file() and is_symlink(). You are learning what the inputs look like before deciding how to combine them.

An empty directory is a valid input whose result is zero. A missing directory is an invalid input that raises an exception. Treating both as zero would conceal a typo in the user’s path. This is a domain decision in the contract, not a property of integer arithmetic.

Practice the accumulation idea on simpler data

total_bytes = 0
for size in [12, 8, 5]:
    total_bytes = total_bytes + size
print(total_bytes)

Trace total_bytes after each iteration: 12, 20, 25. If the initialization were inside the loop, earlier work would be lost on every iteration. If a return were inside the loop, the function would stop before processing remaining entries. Your counter uses the same idea, but increases by one only when an entry satisfies the rule.

Use a failing test as a precise question

Read test_counts_only_direct_files_including_hidden. tmp_path gives it a fresh isolated directory. The test creates two direct files and one nested file, then expects 2. If you obtain 3, investigate whether you recursed. If you obtain 1, inspect hidden-file handling. If you obtain None, inspect return placement. A failure narrows your next experiment; it is not a request to replace the whole program.

Hint ladder

1. Validate the path before iteration. 2. Start an integer total at zero. 3. Iterate direct children with iterdir(). 4. Increase the total only for a file that is not a symlink. Return after the loop, not inside it.

Expected result · open after your attempt

The supplied data/count directory contains three direct files, including .hidden; the nested file is excluded. Missing input should produce an error on stderr and exit status 2. Tests also check empty folders, symlinks, and file-as-folder input.
