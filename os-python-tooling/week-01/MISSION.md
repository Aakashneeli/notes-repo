# Mission: Own Python-first AI backend development

## Why
Build, test, debug, deploy, and explain AI backend software independently, instead of depending on generated code that you cannot modify. This goal is taken from your supplied roadmap; your personal motivation and preferred pace are awaiting your reply to the opening question.

## Success looks like
- Week 1: independently implement and explain a file counter, JSON pretty-printer, and log filter.
- Reproduce a Python environment, use focused Git branches, and diagnose basic path/input failures.
- Over 12 weeks: progress toward a tested, deployed backend with persistence, RAG, agent workflows, and clear operating notes.

## Constraints
- Keep materials inside this teaching workspace, with short HTML lessons and hands-on evidence.
- Starting baseline from the roadmap: Python exposure, weak ownership of generated code, some Git basics. Reassess with the first explain-back.
- Roadmap hardware/budget assumptions: no useful GPU and roughly $20/month cloud cap; no paid services required in Week 1.
- The roadmap's 6–8 hours/day included DSA. This course uses flexible sessions and does not require that old daily load.

## Out of scope
- DSA, NeetCode, algorithm interview exercises, complexity drills, and DSA logs across all weeks.
- Full frontend development, model training, Kubernetes practice, and cloud certifications.
