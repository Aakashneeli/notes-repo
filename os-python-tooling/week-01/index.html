A practical field guide for your first week of AI backend engineering.

Understand the command. Trace a worked example. Practice one small skill. Build and explain the tool.

Start today: lessons 01–03. Work through the whole week at your pace; the complete Week 1 material is ready. DSA is excluded from the entire course plan.

The Week 1 syllabus

  1. 01Make learning observableFinish one tiny experiment and leave evidence you understand it.
  2. 02Know where commands runLocate a file using both an absolute and a relative path.
  3. 03Find the evidence in filesLocate error lines without opening a large file in an editor.
  4. 04Understand a program’s surroundingsPass a setting to Python and inspect a file’s permissions.
  5. 05Make a commit you can explainStage one intentional change and inspect exactly what you commit.
  6. 06Move a change through reviewCreate a branch, merge it, and rehearse remote collaboration locally.
  7. 07Own your Python environmentIdentify which Python executes your project and where dependencies live.
  8. 08Predict values before running codeExplain the difference between a name, a value, and its type.
  9. 09Choose a collection for real dataRepresent filenames, one log record, and unique levels in Python.
  10. 10Turn a rule into a functionWrite a small function whose result you can test.
  11. 11Connect Python to a fileRead JSON and distinguish filesystem paths from imports.
  12. ↳Practice before the projects12 small exercises in four rounds, with hints, worked answers and automatic checks.
  13. ↳Read every line of a commandA complete greeting CLI explains argument parsing, errors, exit codes and tests.
  14. 12Build a file counterImplement your first toolbox command on its own Git branch.
  15. 13Build a JSON pretty-printerFormat JSON without changing its meaning or source file.
  16. 14Build a precise log filterSelect exact log levels while preserving event order.
  17. 15Prove that the tools are yoursRun a fresh checkout, repair a bug, and explain the whole flow.
